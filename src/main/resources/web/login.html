Default Accounts & Database

The PulseFit portal is provisioned with default accounts stored persistently in data/users.json:

Admin: admin / admin123 (Full system control)
Technician: technician / tech123 (Triaging & repairs)
Trainer/Staff: trainer / staff123 (Reporting incidents)

You can also register a brand new account using the Register New User tab, which will immediately be saved to the database.
